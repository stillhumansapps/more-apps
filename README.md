# More Apps highlights

Big banners and badges for the **More Apps** sheet in Still Humans apps, served by GitHub Pages:

- `highlights.json` → https://stillhumansapps.github.io/more-apps/highlights.json
- `banners/` → banner images (file names carry a content hash, so a new image gets a new URL)

Published by **App Factory → Cross Promotion → Publish banners & badges**
(`tools/publish_more_apps_highlights.py`). Do not edit by hand: the next publish overwrites it.

The small cards are not here: they stay in `https://mindblows.com/cross-promo.json`.
